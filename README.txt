# Ahmed Aladdin — Editable SEO Portfolio

## Files
- `index.html`: page structure and section headings.
- `styles.css`: all design, colors, layout, typography, and responsive behavior.
- `script.js`: renders the content into the page.
- `data.js`: **the main file you should edit** to change your name, bio, experience, skills, projects, services, contact details, and metrics.
- `assets/`: your supplied Google Search Console screenshots.

## Edit your information
Open `data.js` in Visual Studio Code. Change the text inside quotation marks. Keep commas and quotation marks intact.
- Add your LinkedIn URL in `linkedin`.
- Add a public CV URL in `cv` if you want a CV button later.
- You can edit each project, metric, and screenshot caption in this file.

## Preview
Open `index.html` in your browser. For best local preview, use the VS Code extension "Live Server".

## Publish on Vercel
Upload all files and the `assets` folder to your existing GitHub repository. Keep the files at the repository root. Vercel should redeploy automatically after the GitHub commit.

This is a static HTML/CSS/JS website; no build command is required and the output directory can remain blank/default.
