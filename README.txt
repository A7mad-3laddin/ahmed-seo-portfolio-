طريقة النشر على Vercel:
1) فك ضغط الملف على جهازك.
2) ارفع محتويات المجلد إلى مستودع جديد على GitHub (وليس ملف ZIP نفسه).
3) من لوحة Vercel اضغط Add New ثم Project.
4) اختر مستودع GitHub الذي رفعت إليه الملفات، ثم Import.
5) اترك Framework Preset على Other، ولا تحتاج إلى Build Command أو Output Directory.
6) اضغط Deploy.

تعديلات مهمة قبل النشر:
- افتح index.html وابحث عن YOUR_EMAIL@example.com واستبدله ببريدك الحقيقي.
- راجع الاسم وطريقة وصف الخدمات والمشروعات وأي تفاصيل تريد تعديلها.
- لا تضف أرقام زيارات أو نتائج أو نسب نمو إلا إذا كانت لديك بيانات موثقة.
- يمكن إضافة روابط LinkedIn وWhatsApp بعد توفيرها.

الموقع Static HTML/CSS/JS ولا يحتاج إلى تثبيت Node.js أو إعدادات بناء.
